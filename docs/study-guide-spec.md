## Using AI to Analyze and Learn from a Codebase
Use the following prompt to create a study guide specification for analyzing a Codebase:

`Given I am a Software Engineering Student and this Codebase is an example of a RESTful API, part of the Web Applications course I am enrolled in, so analyze the codebase and help me understand the approaches, patterns, Framework and language features applied, so I can apply them in my own projects. Based on this, create a Study Guide, including detailed explanations and references for each relevant topic, so I as an student can use it as a source for learning and developing my skills.`
